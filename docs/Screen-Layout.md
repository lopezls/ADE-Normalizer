## Screen Layout

Three panels, side by side, updating as the call happens:

<img width="689" height="440" alt="Screenshot 2026-10-04 230927" src="https://github.com/user-attachments/assets/fde16597-4474-4275-aae6-b0e8cc91b03e" />

| Panel | What it shows |
|---|---|
| **Left: Checklist** | Required call steps and conditional steps. Each item is red until the pharmacist completes it, then turns green. Conditional items (for example, adherence tips after a missed dose) appear in red when the patient's report triggers them |
| **Center: Live chart note** | The chart note builds itself as the call progresses: drug, consent, missed doses, events (verbatim wording beside the standardized label), and the interventions the pharmacist actually gives. The pharmacist can edit any entry |
| **Center, below the note: "What the AI heard"** | A collapsible strip showing the transcript, so the pharmacist can check what the AI heard. It is shown for the session only and is not stored |
| **Right: Recommendations** | When something the patient reports matches a rule, a suggestion appears with its rule ID, for the pharmacist to use or ignore in their own words |
